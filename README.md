# Somayeh (Hosseini) Dana — Personal Website

Live website: https://somayehdana.github.io/

Static, responsive portfolio website based on the current academic CV and public professional profiles.

## Preview

Open `index.html` directly, or run a local web server in this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a public repository named `somayehdana.github.io`.
2. Upload the contents of this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.

The website will then be available at `https://somayehdana.github.io/`.
